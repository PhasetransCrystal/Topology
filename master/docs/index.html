使用 Topology 注册内容

Topology 是面向 NeoForge 的内容开发框架，提供材料、装备、机器、管道、配方和矿脉的注册与运行机制。 你的模组声明类型、策略和具体内容，Topo 宿主负责在对应阶段调用插件、生成游戏条目并冻结注册表。 Topo 本体不提供铜、锡、粉碎机等玩法内容；仓库中的 TopoDemo 是独立开发模组，不随框架发布。

按目标开始​

你要做什么从哪里开始完成后得到什么
在自己的模组里注册第一项内容快速开始一个接入宿主的 TopoPlugin，以及从材料数据生成的物品
组织材料、机器、配方等完整内容链内容注册实作按钩子分工的声明、策略和数据生成
使用原版或其他模组的物品、方块、配方与能力兼容其他模组引用现有条目、覆盖材料形态、接入配方和资源传输
复用或扩展另一个 TopoPlugin 的类型与内容兼容其他 TopoPlugin共享数据类型、跨插件形态匹配与配方贡献
查某个注册窗口或可用时点插件生命周期钩子、冻结点及游戏对象绑定顺序

内容通过什么入口注册​

TopoPlugins.register(new MyContentPlugin(myRegistry));

在模组构造期登记插件。插件继承 TopoPlugin，覆写需要的钩子，使用钩子参数提供的领域入口：

内容常用入口注册位置
材料数据类型、形态、后处理器material.dataType / .form / .postProcessorregisterMaterialFoundation
材料及其属性material.materialregisterMaterials
装备种类equipment.kindregisterEquipmentKinds
机器machine.machineregisterMachines
管道machine.piperegisterMachineFollowUps
配方能力与类型recipe.capability / .recipeTyperegisterRecipeFoundation / registerRecipeTypes
具体配方已声明的 recipeType.reciperegisterRecipes
矿脉ore.veinregisterOreVeins
独立翻译、运行时绑定lang.key / runtime.tooltip / .itemBehaviorregisterLang / registerRuntime

领域入口接收裸路径，例如 material.material("tin") 自动归属当前插件的 mymod:tin。 普通物品、方块和创造栏可在合适的插件钩子中使用同一个 RegistryCore 注册。 完整可运行的声明方式见快速开始，各领域的策略写法见下表。

按领域查用法​

领域注册与扩展
材料材料、形态策略、数据类型、后处理器
装备装备种类、机器交互行为、悬浮信息
机器机器注册、组件、资源端口、渲染、UI
多方块蓝图、部件角色与状态显示
管道管道注册、分发策略、网络勘测
配方具体配方、配方类型、输入输出能力
矿脉矿脉注册、生成策略、预览
文本与工具本地化、条目显示名、工具类、测试与验证

跨 TopoPlugin 的依赖通过所属模组之间的依赖关系隐式确认，插件无需再声明一份依赖图。 扩展其他模组时先确定依赖和内容归属，再按生命周期使用对方公开的句柄；详见两篇兼容指南。
