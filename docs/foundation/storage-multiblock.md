# 多方块只是业务接入示例

面向框架开发者。此设计尚未实现；除用户明确的边界外，接口形态仍待审阅。


多方块侧根据蓝图与结构元数据解析确切物品需求，使用 `StorageAccess<ItemResource>` 实际取出，按实际施工核算消耗。
余料和拆除所得通过通用存入操作处理；多方块执行层决定最终剩余物品掉落的位置。
创造模式在调用前选择无条件满足取出需求的虚拟提供器，普通玩家选择真实仓储；接口实现均返回相同形态的结果，放置核心统一处理。
真实仓储实现表示资源从存储转出，虚拟实现表示由其供应策略提供资源；公共结果契约不要求每种实现都有实际库存或槽位。
通用仓储层不判断玩家模式；虚拟实现也不要求绑定玩家。存入方向的接收策略单独配置。
已有方块不覆盖、建造权限复核和施工回滚由多方块流程负责。

同一套公共契约还可供非多方块机器批量供料、物品转运或流体存取使用；这些场景不应导入多方块或机器数据容器。
