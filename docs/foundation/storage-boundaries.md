# 通用仓储访问的已确认边界

面向框架开发者；保留已有来源和适用范围。


- `StorageAccess` 是框架通用仓储访问接口，多方块工具只是调用方之一；不依赖蓝图、Cell、`StructureTool`、机器数据域或结构元数据。存储目标、访问身份和权限由实现或适配层封装。
- 批量取出与接收均输入需求 Map，返回实际满足与剩余需求两个 Map；后续实例直接处理剩余需求，不重复扣减，保留物品组件与数量。业务核算、访问顺序和最终剩余处理由调用方负责，通用接口不默认掉落物品。
- 不要求槽位、全量库存或内容快照；背包、绑定箱子、AE 网络、精妙存储背包等由各自实现处理高效访问，不按 Cell／备选反复读仓储。AE 适配按需求键访问网络。
- 公共接口接收混合资源批次并返回实际转移，不保证跨仓储回滚。原版槽位实现每批使用一个内部事务；AE 的执行直接修改网络。

来源：用户于 2026-11-08 至 2026-11-09 的直接要求。接口实现和约束见 [StorageAccess 仓储访问设计](design-index.md)，多方块接入流程见 [多方块检测与结构工具设计](../machine/design-index.md)。
