# 结构工具验证

面向框架开发者。以下记录结构工具的手动验收范围。

新增回归用例使用 4×4×6 中空蓝图，覆盖 24 向、镜像、声明坐标旋转、方向属性、已有方块冲突、
未知位置、材料选择、槽位分配、模块编号及协议边界。
配置回归另覆盖控制器前后重复段、双层重复组、可选段、移动顶盖，以及超过完整背包容量的分批补建。按项目约定，由开发者手动运行：

```bash
./gradlew test --tests 'net.ptcrys.topo.api.machine.multiblock.*' --rerun
./gradlew runClientData
./gradlew runClient
```

游戏中重点验收大尺寸 Demo 的本体与模块：普通右键配置、检测与虚影、重复段和镜像、
创造补建、生存少量材料分批补建与跨槽扣除、已有方块不覆盖、空气内腔冲突、放置事件取消、区块卸载及收起工具。
组合塔重复次数示例为 `2,3,1`：下段两份、上段三份双层组、可选横梁一份。
编译通过不代替游戏验收。
