# 验证内容插件

面向使用 Topology 的模组开发者。本页说明验证插件集成时应检查的行为；具体运行配置与生成目录以你的项目为准。

1. 使用自己的 datagen 配置生成资源，并检查模组 ID、输出目录与资源是否加入构建产物。注册条目、生成资源和加入创造栏是独立步骤。
2. 在游戏中检查条目 ID、名称、模型、配方及机器交互；不能用编译成功代替运行验证。
3. 测试兼容时分别检查目标模组存在和缺席的情况，并确认标签、配方和能力传输的实际行为。
4. 检查专用服务端能启动，且公共代码不加载客户端专用类。

NeoForge 测试和运行配置依赖你的开发环境。跨插件注册时点见[插件生命周期](lifecycle.md)，兼容边界见[兼容其他模组](../compatibility/other-mods.md)。
