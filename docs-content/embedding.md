# 集成宿主

面向集成 Topology 的模组开发者。当前支持依赖 `topo` 宿主的集成方式：在模组依赖中声明 `topo`，并在构造期登记自己的 `TopoPlugin`，详见[快速开始](getting-started.md)。

宿主负责框架启动、事件接线及共享注册表。内容插件不需要重复执行宿主接线或手动冻结注册表。插件必须在模组构造期登记；注册及对象绑定时点见[插件生命周期](foundation/lifecycle.md)。

完全移除 `topo` 宿主的内嵌方式目前不受支持：共享条目和部分事件订阅依赖该宿主，复制接线不能完成迁移。
